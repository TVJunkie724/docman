# REG-06 Data Act Portability Cloud Switching

## Purpose

Defines portability, export and provider-switching expectations.

## Required Decisions

- User/customer data categories.
- Export formats and machine readability.
- Cloud switching and offboarding duties.
- Data deletion after export/offboarding.
- Vendor lock-in risks.
- Contract and support implications.

## Stop Rules

- Stop if cloud/sync/storage service design prevents export, deletion or
  provider switching without explicit decision.
