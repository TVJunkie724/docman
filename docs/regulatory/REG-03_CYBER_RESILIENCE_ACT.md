# REG-03 Cyber Resilience Act

## Purpose

Defines Cyber Resilience Act readiness for products with digital elements.

## Required Decisions

- Product classification and applicability.
- Secure-by-design and secure-by-default requirements.
- Vulnerability management and disclosure process.
- Security update policy and support window.
- SBOM and dependency security.
- Incident/vulnerability reporting obligations.
- Conformity assessment and technical documentation owner.

## Product Requirements

- Security support window is visible.
- Update mechanisms are documented.
- Dependencies are tracked and reviewable.
- Vulnerability intake and triage exists before commercial release.

## Stop Rules

- Stop if a sellable product has no vulnerability process, security update
  policy, SBOM/dependency strategy or support window.
