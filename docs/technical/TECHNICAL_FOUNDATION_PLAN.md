# Superseded - Technical Foundation Plan

Dieser fruehere Home-Hub-/Local-first-Plan autorisiert keine Implementierung.
Die aktuelle Foundation wird als C1 `Vault, Account and Provider Foundation`
aus `docs/ROADMAP_REBUILD.md` geplant.

Verbindliche technische Grundlagen sind insbesondere F1-F7, F10-F12, F15-F18,
die Vault-/Account-/Assist-Entscheidungen, der aktuelle Phase Index und ein
gepruefter Phase-as-Implementation-Contract. Der alte Detailplan wird nicht
erhalten, weil konkrete Home-Hub-, Pairing-, Draft-Inbox- und Providerangaben
Agenten in eine verworfene Architektur fuehren wuerden.
