# AI-04 Confidence Explainability

## Rules

- Confidence and uncertainty are shown where they affect user trust.
- Source evidence links suggestions to input data when possible.
- Low-confidence output asks for review instead of pretending certainty.
- Explanations avoid model internals and use user-safe language.

## Stop Rules

- Stop if users cannot distinguish confirmed data from uncertain suggestions.
