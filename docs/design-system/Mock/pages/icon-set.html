Icon Set

Lucide ist das primaere Produkt-Icon-Set.

Icons sind Funktionssprache, nicht Dekoration. Ordna nutzt ruhige Outline-Icons mit einheitlicher Strichstaerke, klaren Labels und sparsamer Farbe. Das App-Symbol bleibt getrennt vom Produkt-Icon-Set.

Icon Regeln

Dokument scannen Exportieren Tag setzen
Icon plus Text

Sicherheits- und Dokumentaktionen brauchen immer ein lesbares Label.

RegelEntscheidung
PrimaerfamilieLucide Outline Icons, 20px oder 24px, konsistente Strichstaerke.
FarbeIcons erben Textfarbe; Statusfarbe nur mit sichtbarem Text oder Statusobjekt.
Icon-onlyNur fuer sehr bekannte Toolbar-Aktionen, immer mit Tooltip und Accessibility Label.
Icon + TextPflicht fuer Capture, Export, Delete, Pairing, Backup und sicherheitsrelevante Aktionen.
Keine MischungKeine Emojis, keine gefuellten Fremdsets, keine dekorativen Einzelicons.
