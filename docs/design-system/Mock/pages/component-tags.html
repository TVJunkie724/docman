Tags

Tags helfen beim Wiederfinden, ersetzen aber keinen Status.

Tags sind flexible Schlagworte fuer Filter, Suche und persoenliche Ordnung. Workflow-Zustaende wie Entwurf, bezahlt, eingereicht oder erstattet bleiben eigene Status- und Fact-Felder.
