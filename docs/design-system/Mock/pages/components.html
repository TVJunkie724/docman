Component System

Komponenten fuer Dokumentarbeit, nicht fuer Marketing.

Jede Komponente muss Datenzustand, Privacy-Grenze, Accessibility und mobile/desktop Verhalten kennen.

Buttons

Capture, Review abschliessen, Export, Retry, Delete. Actions muessen klar hierarchisiert sein.

Forms

Pflichtfelder, Vorschlaege, Fehlermeldungen, Dirty/Saving, sensible Felder.

Status

Entwurf, erledigt, Sync, Backup, Konflikt, Datenschutz, Erinnerung.

Tags

Filterbare, editierbare Schlagworte ohne Workflow-Bedeutung.

Data Display

Dokumentzeilen, Fact-Gruppen, Vorgangstimeline, Exporthistorie.

Icons

Lucide als ruhiges, konsistentes Produkt-Icon-Set.
