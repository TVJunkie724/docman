## Regeln

- Jeder persistierte Typ/jede Variante/jeder breite Domain-Typ braucht den
  Produktwerttest; universeller Generic/Unknown-Fallback ausgenommen.
- Erkennung allein ist kein Produktwert.
- Plane standardmaessig fuer kleine/mittlere General-Purpose-Modelle. Eine
  Promotion braucht belegte Erkennung auf dieser Zielklasse oder eine einfache
  bewusste Nutzereingabe.
- Fehlende Erkennung erzwingt den vollwertigen sicheren generischen Fallback;
  ein spaeterer feiner Vorschlag benoetigt einen neuen Feasibility-Nachweis.
- Country-/Providerlayout vervielfacht keine globalen IDs.
- Pflichtfelder eines Landes sind Analysehinweise, keine Mappm-Pruefung auf
  rechtliche Gueltigkeit oder Compliance.
